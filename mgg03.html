Bagian 1

Gambar sebagai Data

Memahami struktur piksel, saluran warna, dan tantangan representasi data gambar.

Transisi ke bagian pertama. Fokus pada struktur spasial gambar dan alasan model perlu mempertahankan hubungan lokal.

Bagian 2

Convolutional Neural Networks

Memanfaatkan struktur lokal, parameter sharing, dan hierarki fitur untuk membaca gambar.

Masuk ke CNN sebagai arsitektur yang sesuai dengan struktur grid data gambar.

Mengapa CNN untuk Gambar?

Local Receptive Field

Neuron melihat area kecil sehingga hubungan lokal tetap terjaga.

Parameter Sharing

Kernel yang sama mencari pola di berbagai lokasi gambar.

Equivariance

Pergeseran input menghasilkan pergeseran pola pada feature map.

compress
Lebih sedikit parameter, lebih banyak struktur visual yang dipertahankan.
Bandingkan dengan fully connected layer: semua piksel terhubung ke semua neuron, tanpa bias spasial.

Pooling: Merangkum Aktivasi

Max Pooling

max(·)

Mempertahankan respons paling kuat.

Average Pooling

mean(·)

Merangkum respons secara rata-rata.

Efek utama

  • Dimensi spasial lebih kecil.
  • Komputasi berikutnya lebih ringan.
  • Lebih toleran terhadap pergeseran kecil.
Pooling bukan pengganti konvolusi. Ia merangkum feature map dan mengurangi resolusi spasial.

Bagian 3

Evolusi Arsitektur CNN

Dari jaringan konvolusional awal hingga ResNet yang memungkinkan model lebih dalam.

Masuk ke sejarah singkat CNN dan alasan residual connection diperlukan pada jaringan yang lebih dalam.

LeNet, AlexNet, dan VGG

Fokus pada ide yang dibawa tiap arsitektur, bukan menghafal semua konfigurasi layer.

ResNet: Belajar Residual

Masalah

Jaringan sangat dalam dapat mengalami vanishing gradients.

Solusi

Pelajari perubahan residual $F(x)$, lalu tambahkan kembali input $x$.

Residual block mempermudah aliran gradien. Ini memungkinkan backbone sangat dalam seperti ResNet-50.
Bagian 4

Pre-trained Models & Transfer Learning

Memanfaatkan pengetahuan visual yang telah dipelajari untuk tugas gambar baru.

Hubungkan ke masalah nyata: dataset khusus sering kecil, sementara model besar mahal dilatih dari awal.

Dua Cara Memakai Model Pre-trained

Feature Extraction

Bekukan backbone, buang classifier terakhir, gunakan outputnya sebagai vektor fitur.

Cepat dan cocok ketika data target terbatas.

Fine-tuning

Buka sebagian layer dan sesuaikan dengan data target memakai learning rate kecil.

Lebih adaptif, tetapi lebih sensitif terhadap data dan konfigurasi.
Hari ini hands-on memilih feature extraction agar fokus pada representasi, bukan pelatihan.

Data Augmentation

Tujuan

Membuat variasi masuk akal dari gambar yang ada agar model tidak menghafal contoh pelatihan.

auto_fix_high
Augmentasi harus menjaga label tetap benar.
Geometrik rotasi, crop, flip, translasi.
Warna brightness, contrast, saturation.
Occlusion noise atau random erasing.
Tekankan bahwa transformasi yang valid bergantung domain. Flip vertikal bisa tidak valid untuk citra medis tertentu.

Rangkuman & Poin Kunci

Benang merah representasi gambar dari struktur piksel hingga embedding visual berbasis model pre-trained.

Evolusi Representasi

  • Piksel & Saluran → struktur spasial dan warna
  • Konvolusi → pola lokal dan feature map
  • Pooling → ringkasan spasial dan invariansi kecil

Evolusi Arsitektur

  • LeNet, AlexNet, VGG → CNN semakin dalam
  • ResNet → residual connection
  • Pre-trained Model → fitur siap pakai

Kunci untuk Multimodal: Representasi visual yang baik adalah fondasi untuk sistem multimodal — dari image captioning hingga visual question answering.

Rangkum alur dari piksel ke feature map, lalu ke embedding visual. Tekankan bahwa model pre-trained memungkinkan representasi gambar digunakan kembali dalam berbagai tugas multimodal.
